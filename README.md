# Angel Pet Shop - Modern E-Commerce Landing Website 🐾

A modern, high-converting, mobile-first responsive landing website for **Angel Pet Shop**, located in Ghatkopar West, Mumbai.

## 🚀 Features
- **Clean Aesthetic Blue Palette**: Tailored typography (*Outfit* & *Plus Jakarta Sans*), rich sapphire accents, and responsive layout.
- **Interactive Product Catalog**: 12 authentic Indian pet products (Royal Canin, Farmina N&D, Whiskas, Sheba, Drools, Gnawlers, Bio-Groom, etc.) with real-time INR (₹) price calculation based on package variant selection.
- **WhatsApp 1-Click Ordering**: Every card pre-fills a detailed message with product name, selected variant, price, and Ghatkopar delivery inquiry to `+91 95943 41999`.
- **Multi-Item WhatsApp Bundle Cart**: Slide-out drawer allowing pet parents to assemble a custom shopping basket and checkout via a single WhatsApp message.
- **Store Hours & Real-time Status**: Live indicator showing `Open Now · Closes at 10:30 PM`.
- **Location & Google Maps**: Embedded interactive Google Maps iframe with direct navigation link to Asalpha Village / Ghatkopar West.

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS CDN
- Vanilla JavaScript
- Lucide Icons
